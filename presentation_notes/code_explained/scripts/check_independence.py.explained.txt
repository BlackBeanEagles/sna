0001 | """Are the trials independent? They are not — how much does it matter?
0002 | 
0003 | The trial table has one row per (player, behaviour, k-th exposure). That means
0004 | a single player-behaviour spell contributes several rows, and — because
0005 | `adopted` is scored for every exposure whose window contains the adoption —
0006 | one real adoption event can be counted many times over.
0007 | 
0008 | Earlier reports counted many exposure rows per eventual adoption. Trial-level
0009 | Wilson intervals and z-scores assume independent observations and can be too
0010 | narrow when players and behaviours recur. The current numbers are printed by
0011 | this script from the selected game table.
0012 | This script recomputes the headline comparison with ONE row per spell, so each
0013 | player-behaviour contributes exactly one observation and each adoption is
0014 | counted exactly once. If the excess-over-null decay survives that, the finding
0015 | is not an artefact of pseudo-replication.
0016 | 
0017 |     python scripts/check_independence.py --reps 3
