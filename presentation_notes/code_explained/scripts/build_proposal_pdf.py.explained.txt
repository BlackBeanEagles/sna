0001 | """Compile the proposal to PDF without altering the submitted source.
0002 |
0003 | The proposal must keep the course template's preamble byte for byte. That
0004 | preamble relies on pdfLaTeX: `\\usepackage{times}` maps to the Type-1 Times
0005 | fonts through OT1/T1 encoding. A Unicode engine (XeTeX, which is what the
0006 | portable Tectonic binary runs) never selects those mappings, so every \\textbf
0007 | and \\textit silently falls back to the regular face -- headings, the title
0008 | table labels, the methodology sub-headings, every journal name.
0009 |
0010 | So: compile a throwaway copy with `\\usepackage[T1]{fontenc}` inserted. That
0011 | single line only restores the font mapping pdfLaTeX would have used anyway,
0012 | so the PDF matches what the unmodified source produces on Overleaf, and the
0013 | file that gets submitted is untouched.
0014 |
0015 |     python scripts/build_proposal_pdf.py --tex ../SNA_Proposal/SNA_Proposal.tex
0016 | """
